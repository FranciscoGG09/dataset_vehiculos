# 🚗 Panel de Control de Análisis de Vehículos

## 🌐 Aplicación Desplegada
**URL:** https://vehicle-analysis-dashboard.onrender.com

## 📊 Descripción
Aplicación web interactiva para análisis exploratorio de datos de vehículos usados del dataset CarDekho.

## 🚀 Cómo Usar
1. Visita la URL arriba
2. Explora los datos usando los controles interactivos
3. Genera histogramas, gráficos de dispersión y de barras

## 🛠️ Tecnologías
- Streamlit, Plotly Express, Pandas
- Desplegado en Render
